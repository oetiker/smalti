# Extra glyphs for Tamzen 7x14.
#
# Format:  CHAR U+XXXX  <official Unicode name>
#          followed by exactly 14 rows of exactly 7 characters
#          '#' = ink, '.' = background.  Blank lines and #-comments ignored.
#
# Geometry, taken from the existing glyphs:
#   cell        7 wide, 14 tall
#   columns     the body lives in 1..5; 0 and 6 are the side bearings.
#               Using 0 and 6 is allowed and 20 upstream glyphs do it -- to
#               join across cells ('_'), to get the width ('%' '&' 'AE'), or
#               to lean toward the text ('<<' sits in 3..6, '>>' in 1..4).
#               The only cost is that the glyph touches its neighbour.
#   rows        0..10 above the baseline, 11..13 below it.
#               row 10 IS the baseline row (last row of 'x', 'A', 'o').
#   cap height  rows 3..10   (see 'A')
#   x-height    rows 5..10   (see 'x')
#   math axis   row 7        (see '-', '+', '='; '=' uses rows 5 and 8)
#   descender   rows 11..12  (see 'g'); '$' reaches rows 2..12.
