Smalti are the small glass tiles a mosaic is made from. A pixel is one. This is a {{CELL_W}}×{{CELL_H}} bitmap terminal font, forked from Tamzen, in which every glyph is an ASCII-art text file — {{GLYPHS}} of them per face, {{HAND}} drawn by hand in this repository. The drawings are the font. The font files are what the build spits out afterwards.

01 Specimen

Everything below is the real font, loaded as a web font and rendered as text by your browser. It is set at 14, 28 and 42 px — the cell height and its multiples — because that is where the outlines land exactly on the pixel grid and reproduce the bitmap with no antialiasing at all. At 17 px it would blur, which is why no size in between is offered.

If these look soft, your display is running at a fractional scale factor: 14 CSS pixels then land on 21 device pixels and no outline can be exact at a half-pixel. It is crisp at 100%, 200% and 300%.

02 Coverage

Coverage here is ragged on purpose. A face with no drawings at all still builds — it comes out as plain upstream Tamzen — so nothing is ever blocked on nobody having drawn ✦ yet. What follows is the whole truth about what this font has, where it came from, and what it is missing.

Who drew what

A drawing beats a computation; a computation beats nothing. Every glyph in every face comes from exactly one of three places, and this is the count per face — the same numbers make index writes into docs/coverage.md.

Block by block

Each strip below is one Unicode block, one tile per codepoint, in order. A lit tile is a glyph this font has. An empty socket is a glyph nobody has drawn yet — click one and you can be the person who does. A crossed tile is a codepoint left undrawn by rule: it is East Asian Wide, so a terminal gives it two cells and takes it from the emoji font, and a {{CELL_W}}×{{CELL_H}} bitmap for it would be both unused and the wrong width.

Two counting notes, so the numbers can be checked. Each face holds {{GLYPHS}} glyphs but its cmap has {{CMAP}} entries: .notdef is glyph 0 and is deliberately not mapped, which is correct and not a gap. And a block's target excludes unassigned codepoints, surrogates, control codes and the private use area — what belongs in those is a judgement this font makes one codepoint at a time, so they are counted as extras rather than counted against.
